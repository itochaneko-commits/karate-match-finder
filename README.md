# 出場試合ファインダー

karate-network.com の公開データ（大会情報・コート進行）を使って、名前 / 所属（支部・道場・流派） / 階級（型・組手）で出場試合・コート・対戦相手を検索できるツールです。

- `index.html` — アプリ本体（単一HTMLファイル、ビルド不要）
- データは `karate-network.com` から**ブラウザが直接**ライブ取得します（30秒ごと自動更新）
- 対象大会IDは `index.html` 内の `COMP_ID` 定数で指定（現在: 50）

## 使い方
`index.html` をブラウザで開くだけ。ホスティングすればスマホからも利用でき、「ホーム画面に追加」でアプリのように使えます。
